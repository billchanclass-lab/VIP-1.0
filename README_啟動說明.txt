VIP 經營雷達｜行情介接原型

啟動方式
1. 將 ZIP 內的 VIP經營雷達_玉山證券版.html 與 server.js 放在同一資料夾。
2. 電腦需安裝 Node.js 18 或以上版本。
3. 在該資料夾執行：node server.js
4. 瀏覽器開啟：http://127.0.0.1:4173
5. 進入「庫存與個股分析」，選取股票後按「更新行情」。

行情介接
- 後端讀取 Yahoo Finance Chart 的台股代碼（例如 2330.TW），回傳最新可取得的價格、漲跌及行情時間。
- Yahoo API 為未公開的資料端點，可能調整、限流或停止服務；此原型不保證交易所即時行情，也不作為下單依據。
- 直接雙擊 HTML（file://）不會啟動行情代理，需用上述本機服務開啟。

資料與功能範圍
- 分公司戰報第一頁使用使用者提供之 Excel 第一工作表「分公司戰報」截至 10/7 的實際欄位與數字，並沿用原表排名。
- 客戶、持倉、成本、風險指標及研究摘要仍是原型示範資料，不是真實客戶資料；Yahoo 行情只替換頁面選取標的的現價資訊。
- 「上傳週報 Excel」按鈕已恢復，目前提供選檔入口，尚未實作將上傳檔案解析並覆蓋儀表板資料。
